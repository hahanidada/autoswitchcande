# autoSwitchCandE

根据 Python 文件中的光标位置，自动切换微软拼音的中英文模式，减少写代码、注释和字符串时的手动切换。

## 使用方法

1. 通过 VS Code 扩展面板的 **Install from VSIX…（从 VSIX 安装）** 安装打包生成的 `.vsix` 文件。
2. 选择微软拼音，打开 `.py` 文件；插件激活后默认启用。
3. 状态栏右侧显示 **自动切换：已启用**。点击变为 **自动切换：已暂停**，再次点击恢复；恢复后的下一次光标移动会重新判断输入模式。

当前根据光标或选区变化触发判断，规则按以下优先级执行：

| 使用场景 | 输入模式 |
| --- | --- |
| 紧邻光标的左右各一个字符中，任意一个是汉字 | 中文，优先于下面的规则 |
| Python 单行注释、行尾 `#` 注释 | 中文 |
| 当前行的字符串内容 | 中文 |
| 其余代码区域 | 英文 |

识别会处理转义引号，字符串内的 `#` 不会被当作注释。目前只分析当前行，Markdown 自动识别尚未接入。需要保持手动选择时，可点击状态栏暂停自动切换。

## 核心接口实现

扩展通过 `src/extension.ts` 中的 `requestIme(action)`，异步调用由 `native/ImeMode.cs` 编译生成的 `native/ImeMode.exe`：

| 参数 | 作用 |
| --- | --- |
| `get` | 读取当前输入状态，返回候选模式及原始状态数据 |
| `zh` | 明确请求中文模式 |
| `en` | 明确请求英文模式 |

C# 辅助程序定位前台 VS Code 的焦点控件，通过默认 IME 窗口和 Windows 消息读取、设置输入状态。调用包含焦点复查、超时和设置后的回读校验；成功输出 JSON，失败通过错误输出和非零退出码返回。控制的是同一输入法的中英文模式，不负责切换输入法或键盘布局。

扩展运行时必须保留 `native/ImeMode.exe`。接口回读结果仍需结合实际输入验证，不能仅凭返回值认定当前 Windows 与微软拼音版本完全兼容。

## 当前测试范围

- 开发与验证环境：**Windows 11、微软拼音、本地桌面版 VS Code**。当前清单要求 VS Code `1.144.0` 及以上的兼容 1.x 版本。
- 已进行开发阶段模拟验证：单行代码、注释、字符串、转义引号、邻接汉字、切换请求与异常处理，以及暂停开关。
- 真实输入法的候选输入、快速连续切换和不同系统版本兼容性，仍需持续人工验证；尚未验证其他输入法、macOS、Linux、远程开发和网页版。
- `npm test` 目前运行的仍是模板测试，没有覆盖上述场景或真实输入法控制；开发阶段的模拟验证尚未整理为仓库内的回归测试。

## 编译与调试

以下命令均在项目根目录执行，需要准备 Node.js、npm 和 VS Code：

```powershell
npm ci
npm run compile
```

日常修改 `src/`，由编译生成 `out/`。持续编译和代码检查命令：

```powershell
npm run watch
npm run lint
```

修改 C# 源码后，需要单独重新生成辅助程序；`npm run compile` 只编译 TypeScript。当前 Windows 环境可使用：

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" `
  /nologo /target:exe /platform:anycpu `
  /out:.\native\ImeMode.exe .\native\ImeMode.cs
```

调试方式：

- **运行功能**：选择 `Run Extension`，按 **Ctrl+F5** 打开扩展开发宿主，再打开 Python 文件。该启动方式已在当前环境验证可保持窗口打开。
- **断点调试**：当前环境直接 F5 曾出现扩展宿主启动崩溃，可选择备用配置 **Run Extension (Attach)** 后按 F5。它先编译并启动开发宿主，再连接 `127.0.0.1:9333`；实际连接稳定性仍需验证。
- 使用附加方式前，关闭上一轮开发宿主，避免端口冲突；停止附加调试后，开发窗口可能需要手动关闭。初始化可能早于附加完成，建议先在光标监听回调中设置断点。

修改源码后重新编译，并重新加载或启动开发宿主，使新代码生效。

## 打包

```powershell
npx @vscode/vsce package
```

打包会自动先运行 TypeScript 编译，输出 `autoswitchcande-<版本号>.vsix`。它不会重新编译 C#，因此打包前应确保 `native/ImeMode.exe` 已更新。

`.vscodeignore` 已排除开发依赖、测试、开发文档和 C# 源码；运行入口 `out/extension.js` 与辅助程序 `native/ImeMode.exe` 必须保留。当前尚未补充仓库地址和许可证，打包时可能出现对应提示。
